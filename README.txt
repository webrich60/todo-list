TODO管理 v2.7.5 - タスク分類表示版

【更新方法】
1. ZIPを解凍し、現在のindex.htmlをバックアップしてください。
2. index.htmlだけを既存のGitHub Pagesリポジトリの同じ位置へ上書きしてください。
3. todo-header.webpは変更不要です（同一画像を同梱）。
4. Ctrl+Shift+Rで再読み込みしてv2.7.5を確認してください。
GASの変更・再デプロイ・スクリプトプロパティ変更は不要です。

【タスク分類】
・登録済みTODOの上部に「すべて」「継続中」「期限超過」「完了済み」の件数付きボタンを配置。
・すべて表示では期限超過（赤）、継続中（青）、完了済み（緑）の順で表示。
・未完了で期限前、または期限なしは継続中。終了日時が設定されている場合は終了日時を優先し、それ以外は期限を使用。日時は日本時間として判定（日付のみの場合はその日の終了まで）。
・完了済みは期限にかかわらず完了欄へ。未完了に戻すと期限に応じた欄へ移動。
・期限超過と継続中は期限の早い順、完了済みは完了日時の新しい順。
・画面表示中は15秒ごとに期限を再判定。日別カレンダーの予定も3分類で表示。
・従来のカテゴリー別の色、2日前の黄枠、1日前のオレンジ枠、当日の赤枠、操作通知、買い物リスト、GAS接続方式を維持。

JavaScript構文チェック、Chromium 375px幅でサンプルタスクの分類・件数・切替・時刻判定・カレンダー日別分類、模擬保存による完了／未完了への移動と通知を確認。実際のGAS・端末間同期・スマホ通知は未検証です。
